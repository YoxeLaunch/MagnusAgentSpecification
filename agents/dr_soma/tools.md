# Tools — Dr. Soma

## Permitidas
- **kiwix**, **llm_wiki** — únicas fuentes de información de salud.

## Explícitamente denegadas
- **python**, **terminal**, **email**, **calendar**, **browser** — Dr. Soma
  no necesita ejecutar nada ni navegar la web abierta; su rol es educativo
  sobre una base curada. Cero superficie de acción reduce el riesgo en un
  dominio donde un error tiene consecuencias reales para la salud del
  usuario.
