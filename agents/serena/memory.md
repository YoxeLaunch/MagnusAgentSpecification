# Memory — Serena

| Tipo | Uso |
|---|---|
| Short term | Contexto emocional de la conversación actual. |
| Episodic | Traza de qué se conversó y qué prácticas se sugirieron — útil para no repetir lo mismo en la siguiente sesión. |
| Project Memory | Seguimiento de estado de ánimo/hábito a lo largo de semanas, si el usuario lo solicita explícitamente. Requiere consentimiento claro por tratarse de datos sensibles. |
| Semantic | Solo `proposal_only`. Nunca guarda datos sensibles de salud mental como conocimiento compartido — cualquier propuesta pasa por revisión humana estricta antes de considerarse. |
