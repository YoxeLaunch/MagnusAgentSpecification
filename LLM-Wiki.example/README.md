# LLM-Wiki Template

Este directorio sirve como estructura de ejemplo para la **LLM-Wiki** personal de tu instancia de MagnusAgent.

## Instrucciones de Inicio

1. Copia este directorio `LLM-Wiki.example` como `LLM-Wiki`:
   ```bash
   cp -r LLM-Wiki.example LLM-Wiki
   ```
2. Agrega tus propias notas markdown en `LLM-Wiki/wiki/` (o vincula tu bóveda de Obsidian).
3. `LLM-Wiki/` está ignorado en `.gitignore` para garantizar que tus notas personales y privadas nunca se suban por accidente a Git.
